# Templates

## AI implementation task (book Chapter 25)
```
Goal:          one outcome; which task of which feature
Context:       files to read (AGENTS.md, docs/design.md, …); what already exists
Constraints:   layering, conventions, no new dependencies
Acceptance:    testable criteria, including unhappy paths (others' data, duplicates, invalid input)
Out of scope:  what not to touch
Process:       plan + assumptions first; then implement, run `make test`, show the output
```
